# Home Color Lab

Интерактивная сборка cTrader Home из Figma: шторка с темой (Dark/Light/System/Своя), ползунками цвета и яркости для «Своей» и ползунком шрифта.

- `index.html` — готовая self-contained страница (можно открыть как есть или включить GitHub Pages)
- `src/` — исходники сборки (build.py, шаблон, theme.css/js)
